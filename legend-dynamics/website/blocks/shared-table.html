The shared table

Every character creator can join a shared table: the GM starts one, the players join with a code, and everyone sees the same dice, the same characters and the same fight, each on their own device.

Every creator's GM view and GM's Guide are open to everyone. To start a shared table on this site, a GM needs a GM access code: ask for one in the Legend Dynamics Discord server or by email at contact@legenddynamicsrpg.com. Players never need one: they join with the table's code.

Running a game
  1. Start the table. In the creator's GM view, under Shared table, name the game and press Start a table. Starting a table here needs a GM access code: ask in our Discord server or email contact@legenddynamicsrpg.com for one. Type it when the creator asks; it remembers it. Send the players the link (Copy link) or the six-character code.
  2. Players join. Each opens their character, goes to the play tab, types the code and their name, and presses Join.
  3. Play. Rolls from every sheet are rolled by the table and shown to all. Each character appears on the GM's cards, and injuries, points and ammunition stay in step both ways.
  4. Fight. The GM's battle map and encounter show on every player's play tab. Players move their own tokens and, on their turn, send the GM what they do; the GM puts it into the Encounter panel and runs it.
  5. Keep it private. Anyone with the code can join. The GM can Remove a player and Change code at any time.

Each creator has a How a shared game works guide beside the table, for the GM and for players. The creators on this site already use a table server: nothing to set up.

You can mix it with the Discord dice bot: stream the map to a group on Discord while players who have the creator open join the shared table, or roll with the bot while the GM keeps the encounter panel.
